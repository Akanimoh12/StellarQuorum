# Community Calls and Office Hours

This document outlines the regular touchpoints for Stellar Quorum contributors, token holders, and governance participants to ask questions, discuss proposals, and stay informed about upcoming changes.

## Monthly Community Call

**When:** First Monday of each month, 5 PM UTC

**Duration:** 1 hour

**Format:** 
- Live video call on Zoom
- Recording published to [Quorum YouTube](https://www.youtube.com/@StellarQuorum) within 24 hours
- Agenda shared 48 hours before the call; anyone can suggest topics via GitHub Discussions

**Topics Covered:**
- Recent governance proposals and their outcomes
- Upcoming smart contract changes or deployments
- Roadmap updates and feature releases
- Q&A from the community
- Governance education and best practices

**How to Join:**
- Link posted in GitHub Discussions 24 hours before the call
- RSVP appreciated but not required
- Recording available asynchronously

## Weekly Office Hours

**When:** Every Wednesday, 3 PM UTC

**Duration:** 30 minutes

**Format:**
- Voice-only (no recording) on Discord
- Drop in anytime; no RSVP needed
- Unstructured — ask anything

**Topics:**
- Questions about the governance model or how proposals work
- Help getting set up to vote or delegate
- Feedback on frontend usability
- Technical questions for maintainers

## Async Discussion

**Platform:** GitHub Discussions

**Categories:**
- **Governance Questions** — how does X work? should my proposal...?
- **Feedback** — feature requests, UX improvements
- **Ideas** — sharing proposal ideas before formalizing them
- **Announcements** — important updates between calls

All questions get a response within 2 business days; async threads stay open indefinitely.

## Proposal Review Sessions (Ad Hoc)

When contentious or technically complex proposals are live, maintainers may host optional:
- **Deep-dive reviews** — walk through a proposal's mechanics, risks, and rationale
- **Q&A sessions** — open floor for voter concerns before voting closes

These are announced in Discussions at least 3 days before the session.

## Historical Recordings

All past community calls are indexed in [Discussions > Community Calls Archive](https://github.com/StellarQuorum/StellarQuorum/discussions/categories/community-calls-archive) with notes and timestamps.

## For Maintainers: Running a Call

### Before the Call

1. Post agenda 48 hours prior in Discussions (with @StellarQuorum/governance-team ping)
2. Reserve Zoom room and send link to Discussions
3. Prepare talking points (roadmap, recent decisions, PRs to highlight)

### During the Call

1. Record to Zoom Cloud
2. Note Q&A topics and action items
3. Keep call to 1 hour hard stop

### After the Call

1. Download recording and publish to YouTube (unlisted → public after 24h check)
2. Post summary + timestamps + decision log to Discussions
3. Close any action items or create follow-up issues
